# Security

This directory will hold the disclosure SOP for the Mindmint monorepo.

> Until populated, report security issues privately via GitHub Security Advisories at /security/advisories/new (do NOT file a public issue).

## When this directory is populated it should contain

- `disclosure-sop.md` — how to file reports and what triage to expect.
- `threat-model.md` — boundary diagram + assets + adversary list.
- `data-handling.md` — PII / PCI / secrets handling rules.
